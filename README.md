# АРМ оператора испытательного стенда ВЧРП — интерактивный прототип

Прототип интерфейса системы управления и мониторинга испытательного стенда
высоковольтного преобразователя частоты (ВЧРП 6 кВ / 2,0 МВт).
Реализует весь маршрут оператора — от подготовки изделия до протокола испытаний.

## Как открыть

Открыть `index.html` в браузере (Chrome/Edge). Сборка не требуется: чистый
HTML + CSS + JS, без внешних библиотек и сетевых запросов — работает и по `file://`.

### Демонстрационный режим

Чтобы посмотреть интерфейс с уже заполненными данными (модель прокручивается
мгновенно, без ожидания), добавьте к адресу параметры:

| Адрес | Что показывает |
|---|---|
| `index.html?demo=1&view=4` | мониторинг в середине испытания (тренды, приборы, осциллограмма) |
| `index.html?demo=1&view=7` | анализ результатов и вердикт по завершённому испытанию |
| `index.html?demo=1&view=7&proto=1` | то же + открытый предпросмотр протокола |
| `index.html?demo=1&view=5&ff=42` | журнал аварий/предупреждений |
| `index.html?demo=1&view=3&prog=psi3` | программа ПСИ-3 (испытание перегрузкой 1,5 Iн) |

Параметры: `view` — номер этапа (1…7), `prog` — программа (`psi1`…`psi5`),
`ff` — на сколько модельных секунд ускоренно прокрутить испытание.
Без `?demo=1` интерфейс стартует в обычном режиме — как у оператора.

В штатном режиме работу ускоряет селектор **«Скорость модельного времени»**
в правом нижнем углу (`×1 … ×20`): модельное время идёт быстрее реального.

## Этапы (маршрут оператора)

1. **Подготовка и проверка ВЧРП** — паспорт изделия, мнемосхема силового тракта
   с индикацией состояния узлов, чек-лист из 12 проверок (автоматические тесты
   с результатами: сопротивление заземления и изоляции, опрессовка, охлаждение,
   датчики, связь с ПЛК) и допуск стенда к испытанию.
2. **Настройка и запуск испытания** — 5 программ испытаний, уставки защит,
   редактор профиля ступеней, предпросмотр профиля, валидация уставок,
   подтверждение пуска с предпусковыми блокировками.
3. **Проведение в автоматическом режиме** — ход программы, текущая ступень,
   время и остаток, задание/факт, журнал автоматики, автоматические воздействия,
   пауза, штатный останов, E-STOP.
4. **Мониторинг параметров** — 6 стрелочных приборов, тренды скользящего окна
   120 с, осциллограмма трёхфазного напряжения, спектр гармоник и THD,
   таблица 21 канала с min/max/средним и статусами по уставкам.
5. **Предупреждения и аварии** — журнал событий с фильтрами, квитирование,
   разбор события (причины, рекомендуемые действия, реакция системы), баннер
   аварии в шапке, имитация событий для проверки алгоритмов.
6. **Завершение и сохранение** — процедура штатного останова (снижение U/f,
   снятие нагрузки, отключение Q1, разрядка звена DC, заземление, останов
   охлаждения), параметры сессии, список сохраняемых артефактов
   и экспорт (CSV трендов, CSV журнала, CSV осциллограммы, JSON сессии).
7. **Анализ и протокол** — сводная таблица соответствия нормам ТУ,
   статистика по каналам, тренд всего испытания, итоговый вердикт
   и печатная форма протокола (предпросмотр → печать/PDF).

## Модель стенда

* Номинал: 6,0 кВ; 50 Гц; 200 А; 2,0 МВт; звено DC ≈ 8,5 кВ; жидкостное охлаждение.
* 21 канал измерений с уставками «предупреждение/авария» (в том числе по минимуму:
  расход охлаждения, давление, cos φ, КПД, напряжение собственных нужд).
* Защитные отключения по току, температуре IGBT, напряжению и расходу охлаждения;
  событие удерживается до квитирования оператором.
* Контроль производных величин (КПД, cos φ, THD, пульсации) — только в рабочей
  зоне, чтобы обесточенный стенд не давал ложных срабатываний.
* Программы испытаний: ПСИ-1 приёмо-сдаточные, ПСИ-2 диапазон частот,
  ПСИ-3 перегрузка 1,5 Iн, ПСИ-4 проверка защит, ПСИ-5 термоциклирование.
  Для ПСИ-3/ПСИ-4 автоматически применяются соответствующие уставки защиты.
* Протокол считается по фактическим измерениям: нормы ТУ 3411-002-2026
  и ГОСТ Р 51524, вердикт «соответствует / не соответствует» с перечнем отклонений.

## Точки интеграции с реальным стендом

Прототип изолирован от источника данных: UI читает состояние и подписывается
на обновления, поэтому модель заменяется без переписывания интерфейса.

```js
Sim.subscribe(state => { /* state.P — текущие значения, state.hist — тренды */ });
Sim.start(settings, steps, programId);   // пуск
Sim.pause(); Sim.resume(); Sim.normalStop(); Sim.estop();
Sim.raiseAlarm(key, 'alarm' | 'warn' | 'info', value, limit, opts);
```

Для подключения к стенду достаточно заменить в `sim.js` источник значений
`S.P` и трендов `S.hist` на данные ОРС UA / Modbus / ПЛК-шлюза, сохранив
остальной контракт (ключи каналов и уставки — в массиве `CHANNELS`).

## Ограничения прототипа

* Телеметрия модельная (не подключена к реальному оборудованию).
* Экспорт файлов выполняется в браузере (скачивание), запись в архив стенда
  имитируется.
* Протокол формируется на стороне клиента; подписи и согласование — вне прототипа.
